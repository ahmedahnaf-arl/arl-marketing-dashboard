## 1. What this project is

A self-contained, interactive HTML dashboard built from live iBOS ERP data for **Akij Essentials Ltd (BU 144)**. It answers: what did each SKU charge and sell, month by month; what is the declared price architecture; did price or the market drive volume; and what should management decide.

Ten tabs:

| Tab | id | Purpose |
|---|---|---|
| Overview | `ov` | KPIs, monthly revenue, price-direction breadth, channel mix, commentary |
| All SKUs | `sku` | Every SKU: price journey, volume, MoM, elasticity |
| SKU month-on-month | `mom` | Full monthly series for one SKU + commentary |
| Price change tracker | `chg` | Declared price points + largest realised moves |
| Incentives & schemes | `inc` | Trade schemes, booked discounts, free goods |
| Declared price grid | `pg` | DP / TP / MRP coverage and gaps |
| Competition | `cmp` | Like-for-like pack prices vs competitor brands |
| Decision · Direction · Action | `dec` | 5 management blocks + 7P marketing mix |
| Elasticity | `el` | Gated elasticity ranking with per-SKU detail |
| Method & coverage | `mt` | Sources, method, known gaps |

Global filters (**period**, **channel**, **category**) mutate a single in-page `frame`; every KPI, chart, table and the decision tab recompute from it.

## 2. Pipeline

```
ERP (iBOSDDD via enterprise-api-gateway MCP)
        │  refresh.py  (ERP_API_KEY + ERP_DEVICE_ID)
        ▼
ael-price-analysis/data/*.json         (gitignored — raw extracts)
        │  build_categories.js  → data/categories.json
        │  build.js + client.frag.html
        ▼
AEL_Price_Elasticity_Cockpit.html      (gitignored — build output)
        │  copy
        ▼
ael-price-cockpit/index.html  ──git push──▶  GitHub Pages
```

Two ways it runs:

1. **Locally**, by you (below).
2. **Daily in CI** — `.github/workflows/deploy-ael-cockpit.yml`, cron `15 3 * * *` (09:15 Asia/Dhaka), also `workflow_dispatch`. It runs `refresh.py --full`, rebuilds, copies, commits and pushes only if the HTML changed.

## 3. File map (`ael-price-analysis/`)

| File | Role |
|---|---|
| `refresh.py` | **The data layer.** Pulls every dataset from the ERP gateway and writes `data/*.json`. Incremental by default (missing months + last 2), `--full` rebuilds everything, `--probe` prints one month's row counts. Retries transient gateway errors. |
| `build_categories.js` | Maps every SKU to a category from `data/categories_raw.csv` (code → exact name → keyword rule) and writes `data/categories.json`. |
| `build.js` | Server-side build: reads `data/*.json`, computes per-SKU stats, emits the HTML (markup lives here). |
| `client.frag.html` | The browser layer: the `frame` filter model, all rendering, charts, tooltips, DDA/7P logic. Loaded by `build.js`. |
| `config.json` | `{ "buCode": 144, "buName": "Akij Essential", "buShort": "AEL" }` — change this to repoint at another SBU. |
| `import_external.py` | Parses the price & trade-offer workbook into `external/price_master.json` (committed) and `data/external_price_master.json`. Run whenever the workbook changes. |
| `external/price_master.json` | **Committed** parsed workbook — the build reads this, so CI works without the spreadsheet. |
| `external/*.xlsx` | Raw workbook (gitignored, not published). Drop the latest file here to refresh. |
| `verify.js` | Headless render check (jsdom). Must report `errors: []` and non-zero rows in every table. |
| `collect*.js` | Legacy helpers used while the data was scraped interactively through MCP tool output. **Not used by `refresh.py` or CI** — safe to ignore or delete. |
| `.gitignore` | Excludes `data/`, `*.csv`, the built HTML and scratch scripts. |

`data/` files (all regenerated by `refresh.py`):

`panel_full.json` (orders), `channel_full.json` (SKU × channel × month), `snapshot_raw.json` + `price_history_raw.json` + `price_setup_raw_1/2.json` (declared DP/TP/MRP), `competitor_market.json` + `competitor_bench.json`, `schemes.json` + `offers_header.json` + `discount_booked.json`, `delivery_fy.json` + `zones.json`, `pl_monthly.json` (GL P&L), `categories_raw.csv` → `categories.json`.

## 4. Run it locally

Prerequisites: Node 20+, Python 3.12+, and the ERP gateway credentials **in the environment** (never in source):

```powershell
$env:ERP_API_KEY  = "…"     # Bearer token for enterprise-api-gateway
$env:ERP_DEVICE_ID = "…"    # X-Device-Id
```

Then:

```powershell
cd "C:\Users\Hp\Documents\Default Project\ael-price-analysis"

python refresh.py --probe     # optional: one month, prints row counts, no writes
python refresh.py             # incremental pull (~2 min)
python refresh.py --full      # full rebuild of every dataset (~2-4 min)

node build_categories.js
node build.js                 # writes AEL_Price_Elasticity_Cockpit.html

npm i jsdom                   # once, only for verify.js
node verify.js                # must show errors: [] and populated tables
```

Preview: `node server.js` is **not** committed; any static server works, e.g.
`npx http-server -p 8123` then open `http://127.0.0.1:8123/AEL_Price_Elasticity_Cockpit.html`.

## 4b. External workbook (manual input, not from ERP)

The file `Copy of Competitor's Comparison - Price & Trade Offer.xlsx` supplies what the ERP does not:

- **AEL current vs proposed** DP / TP / MRP / trade offer per SKU (49 consumer SKUs).
- **13 competitor brands** × DP / TP / MRP / EDP / ETP / trade offer, per SKU.
- **Sep'26 vs Oct'26 movement**: primary sales, secondary sales and billed outlets per SKU.

To refresh it:

```powershell
python import_external.py --file "C:\path\to\Copy of Competitor's Comparison - Price & Trade Offer.xlsx"
node build.js
git add external/price_master.json ael-price-cockpit/index.html
git commit -m "Refresh price & trade-offer workbook"; git push
```

Notes:
- `external/price_master.json` is committed and read in preference to `data/`; the raw `.xlsx` is gitignored, so a fresh clone rebuilds without the spreadsheet.
- The daily CI job does **not** refresh this file — it is a human-maintained input. Check the `imported` date before trusting the workbook cards.
- The sheet is parsed by fixed column positions (`COL` and `COMP_FIRST` in `import_external.py`). If the sheet is restructured, update those constants — never let columns shift silently.

## 7. Rules that must not be broken

These were learned the hard way. Breaking them silently corrupts the report.

**Gateway limits**
1. No `sys` / `INFORMATION_SCHEMA`, no CTEs, no derived tables in `FROM`, no subqueries in `SELECT` with aggregates. `EXISTS` in `WHERE` works.
2. **Joining `tblSalesOrderHeader` to `tblSalesOrderRow` fails** — the gateway injects an unqualified `intBusinessUnitId` and both tables have it. Filter rows by BU and reach the header only via `EXISTS`.
3. **500-row cap** per response. Aggregate in SQL; split by item code when needed.
4. Two parallel queries are usually fine; three or more → “Connection is busy”. `refresh.py` retries with backoff.
5. A sales-panel file also matches channel files (`c/q/pad`) — any collector must additionally require `g/d/f`, or channel pulls overwrite panel months.

**Numbers**
6. **Fiscal year is July–June**, label = start year (`2026` = FY2026-27).
7. Default the window to the **last complete month**; the live month is partial and makes “active SKUs” look wrong.
8. **UOM guard:** drop months whose unit price is >5× or <1/5 of the SKU median. Apply it on the **client too** — otherwise the decision and elasticity tabs report −99% price moves as real.
9. **Reclass guard in the GL:** when `mfg / revenue > 5%`, cost of sales = `cogs + mfg`, else `cogs`. Without it, single months (AEL Jan-2023) produce impossible margins.
10. MoM/decision deltas use **recent 3 months vs prior 3**, not first-vs-last (that measures structural growth).
11. Elasticity is **gated**: ≥8 pairs, |β| ≤ 5, R² ≥ 0.10, price dispersion ≥ 2%. Unstable fits are excluded and counted, never ranked.
12. Realised price is trade-net → compare against **declared TP or market DP**, not MRP.
13. Never average competitor prices across pack sizes — join on the pack key (`Atta 1kg`, `Miniket 50 KG`).

**COGS — two levels**
14. **BU level: COGS exists** in the GL (4810001). Publish GP% and NP% from it.
15. **SKU level: COGS does not exist.** `sms.tblDeliveryRow.numCogs` = 0 on all 234,781 lines; `itm.tblItem.numAverageRate` implies every top SKU sells below cost; `mes.tblCostSheetHeader` is empty; pre-costing has 6 AEL rows. Do **not** publish a per-SKU margin or a “loss-making SKU” list — use the price-realisation screen instead.

**Reconciliation** (`refresh.py` runs this every time)
16. Panel distinct SKUs must equal `COUNT(DISTINCT strItemCode)` for the same window. Current: **1,032 = 1,032**. If the panel is lower, a month was truncated at 500 rows.

## 9. Known gaps (be explicit with stakeholders)

- **No SKU-level COGS** → no per-SKU P&L, no true loss-making list. Blocked on Finance providing a cost basis (standard cost, or item cost by month).
- **Competitor prices are May–Dec 2024 only** and bulk 50 KG packs carry no MRP/DP — consumer packs only are comparable.
- **Channel data covers 24 months**, so channel filtering outside that window is all-channel by design (the UI says so).
- **Item-level trade discounts** begin 10-Oct-2026; before that only free goods are visible.
- **The price workbook is manual and narrow** — 49 consumer SKUs only, and it does not update itself; treat it as commercial intent, not audited fact.
- **Market share is not in the ERP** — the only external share data lives in a marketing sheet, not wired in.
- **`oms.tblSalesOrderRowDiscount.intItemId` is 0**, so booked discounts cannot be attributed to a SKU.
- **Public repo** — see the warning at the top.

## 10. Troubleshooting

| Symptom | Cause / fix |
|---|---|
| `ERP_API_KEY and ERP_DEVICE_ID must be set` | Export both env vars; CI uses repo secrets. |
| `response was truncated — split the query` | A query crossed 500 rows. Add a filter or split by item code. |
| `Connection is busy` | Transient; retry (script already backs off). |
| `reconciliation: ERP N · panel M` with M lower | A month was capped. Re-pull that month split by `strItemCode`. |
| Category chip empties the table | `cat` missing from the payload — check the `PAY.rows` mapping in `build.js`. |
| Elasticity tab empty | Window too short (needs ≥8 month-pairs) or no usable fits. Widen the period. |
| Page shows stale numbers | `ael-price-cockpit/index.html` was not re-copied after `node build.js`. |
| Push rejected | Others commit to this repo; `git pull --rebase origin master` then push. |
| Charts invisible / off-canvas | Check the SVG y-mapping (`pad.t + …`), a classic source of this bug. |

## 11. Suggested next steps

1. **Get a cost basis from Finance** (standard cost per SKU by month). That single input unlocks SKU GP%, a real loss-making list, and margin-aware elasticity — the biggest remaining gap.
2. **Wire market share** from the marketing sheet so Competition has context, not just price.
3. **Extend channel data to full history** if month-level channel analysis before Nov-2024 matters (57 extra monthly pulls).
